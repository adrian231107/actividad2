Actividad 2 - Juego Snake
#Descripcion
este proyecto es una version modificada del juego Snake implementado con la libreria "turtle" de python.
##Cosas implementadas

-Movimiento impredecible del alimento.

-Ajuste de limites previniendo una apariciones de comida fuera de pantalla.

-Al momento en el que ejecuta el juego la serpiente y la comida tienen colores distintos entre si, son al azar entre 5 colores, excepto el rojo.


Como ejecutar:


python3 snake.py
